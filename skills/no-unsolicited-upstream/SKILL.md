# No unsolicited upstream

Do **not** open, file, create, or publish any of the following unless the user has **explicitly** asked for that exact action in the current turn:

- GitHub/GitLab (or similar) **issues** / bug reports
- **Pull requests** / merge requests
- **Forks** of other people's repositories
- Public **discussions**, RFC comments, or mailing-list posts on the user's behalf
- Contacting maintainers or "reaching out to the community" as the user

## Allowed without that approval

- Local research (reading issues, PRs, docs, source)
- Drafting issue/PR text **in chat** for the user to review
- Linking existing issues the user already knows about
- Pushing / opening PRs only when the user explicitly requested it (see also the repo git/PR user rules)

## If you already did it by mistake

Do not delete or close what you created unless the user asks. Say what you opened and where. Do not dig the hole deeper.
