## Method and reproducibility

All analysis scripts live in `/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts` and use Python's standard library. Run them with isolation enabled:

```sh
python3 -I /home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/analyze.py --cutoff 2026-11-11T00:00:00Z
python3 -I /home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/supplement.py
python3 -I /home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/audit.py
python3 -I /home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/validate.py
python3 -I /home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/write_report.py
```

`analyze.py` streams each JSONL file twice. It uses the first `session_meta.id` as the session identity, derives the project from the working directory, combines worktrees by repository name, and attributes records through thread-owned turn IDs. It parses JSON and shell syntax as data, never executes transcript commands, and does not import transcript-provided modules. It sums unique `token_usage_record.usage` records by response ID. It uses cumulative `token_count` data only when response records are absent. `input_tokens` includes `cached_input_tokens`; `output_tokens` already includes recorded reasoning output, so reasoning is not added again. Missing token fields are `null`; recorded zeros stay zero. [session metrics, 2026-10-17 to 2026-11-10](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/sessions.jsonl); [parser](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/analyze.py).

`n_user_msgs` counts user text rather than injected environment/skill messages, although automated delegation notices and CLI briefs can also use the user role. `n_assistant_msgs` counts assistant text messages, excluding separate reasoning and tool records. `models` comes from owned turn contexts. `is_subagent` uses native source metadata. `n_subagents_spawned` counts recorded native spawn calls. `n_compactions` counts actual compaction records outside copied parent history. `n_interrupts` counts recorded `turn_aborted` events and makes no claim about who caused them. `start` is the session metadata timestamp and `end` is the latest retained response/usage timestamp, not proof the session has ended. [session metrics, 2026-10-17 to 2026-11-10](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/sessions.jsonl); [parser](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/analyze.py).

`tool_calls_by_name` counts recorded outer calls exactly. `tool_errors` counts failed-looking outer results, not individual subprocess errors or independently verified defects. `repeated_reads` lists explicit `cat`/`sed`/`head`/`tail` file targets read in more than 2 tool batches; it does not resolve dynamic shell expressions, file versions or line-range equivalence. Mixed batches count at most once per file. `largest_tool_results` stores the 5 largest compact serialized outputs, plus separate text sizes. Image payloads are excluded from text-byte estimates. Broad command categories and nested-tool mentions are heuristic and overlapping. [session metrics, 2026-10-17 to 2026-11-10](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/sessions.jsonl); [parser](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/analyze.py).

`supplement.py` independently streams structured command-completion events and reads T3 SQLite databases using `mode=ro`, `PRAGMA query_only=ON` and read transactions. The legacy projection contains 3 Codex thread sessions, 161 user messages and 1,022 assistant messages. Its copies in the two databases are not added together. V2 contains 18 Codex provider-thread rows at inspection; normalizing native IDs and legacy runtime cursors links 7 local rollouts. This adds thread associations and orchestration status, not a second source of billable token totals. T3 is live, so its inventory timestamp differs from the rollout cutoff. [Supplement](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/scripts/supplement.py); [audited aggregate, 2026-11-10](/home/mini/Documents/repos/phoe-nix/knowledge/research/agentic-practice-2026-11/data/codex/aggregate.json).
